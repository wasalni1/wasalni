# وصلني — الإصدار 3

## ملفات المشروع (11 ملفاً، كلها في الصفحة الأولى للمستودع)
server.js · push.js · package.json · index.html · admin.html · sw.js · icon.svg · icon-192.png · icon-512.png · README.md · test.js
لا يوجد `npm install` ولا مكتبات خارجية. تجربة محلية: `npm start` ثم `npm test`.

## 1) حفظ البيانات في Supabase (يُنصح به لأن Render المجاني يمسح الملفات)
1. أنشئ مشروعاً في supabase.com ثم افتح **SQL Editor** ونفّذ:
```sql
create table if not exists kv (k text primary key, v jsonb not null);
alter table kv enable row level security;
```
(تفعيل RLS بلا سياسات يمنع أي وصول من المتصفح، والخادم يدخل بمفتاحه السري فقط.)
2. من **Project Settings > API** انسخ **Project URL** ومفتاح **service_role** (أو secret key).
3. في Render > Environment أضف:
   - `SUPABASE_URL` = رابط المشروع
   - `SUPABASE_KEY` = المفتاح السري (لا تضعه في GitHub ولا في أي مكان عام)
4. بعد التشغيل ترى في لوحة الإدارة > نظرة عامة: «التخزين: Supabase». وإن كان الاتصال خاطئاً يتوقف الخادم عن العمل بدل أن يبدأ فارغاً.

## 2) استعادة كلمة السر بالبريد
بدون إعداد يظهر الرمز على الشاشة (وضع تجربة). لإرسال بريد فعلي: حساب في brevo.com، وتحقق من عنوان مرسل، ثم أضف
`BREVO_API_KEY` و`MAIL_FROM` (البريد الذي تحققت منه).

## 3) رسائل التأكيد SMS
أضف `SMS_WEBHOOK` برابط خدمة تستقبل `{phone,text}`، وإلا يظهر الرمز على الشاشة.

## 4) الإشعارات
تعمل Web Push تلقائياً: مفاتيحها تُولَّد وتُحفظ مع البيانات. المستخدم يضغط «تفعيل الإشعارات» مرة واحدة.
على الآيفون يلزم تثبيت التطبيق على الشاشة الرئيسية أولاً (iOS 16.4 فأعلى).

## الرصيد والبونص
شحن رصيد الراكب من الإدارة > الركاب والرصيد. الدفع من الرصيد يُخصم عند انتهاء الرحلة، ويُسجَّل للسائق «له عند المنصة»؛ والكاش تُسجَّل عمولته «عليه للمنصة». التسوية من الإدارة > السائقون.
